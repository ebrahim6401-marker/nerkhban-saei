# نرخ‌بان ساعی برای اندروید

اپ اندروید به همراه ویجت واقعی صفحه اصلی. داخل اپ، داشبورد زنده هر ۵ دقیقه تازه می‌شود. ویجت به‌دلیل محدودیت Android هر ۳۰ دقیقه به‌صورت سیستمی تازه می‌شود و دکمه `↻` برای تازه‌سازی فوری دارد.

برای ساخت APK پروژه را در Android Studio باز کنید و Build > Build APK(s) را اجرا کنید.

پس از انتشار در GitHub، workflow با نام `Build Android APK` به‌صورت خودکار فایل نصب‌شونده را در بخش Artifacts قرار می‌دهد.
